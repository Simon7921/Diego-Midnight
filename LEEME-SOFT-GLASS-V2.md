# Diego Midnight — Soft Glass V2 (prueba visual)

Esta versión usa un cambio visual importante: cabecera deportiva azul noche, superficies perladas/lavanda en relieve, botones suaves y controles verde lima. Conserva los archivos `app.js`, `calc.js` y `store.js` sin alteraciones.

## Instalación

1. Usar únicamente el repositorio de pruebas `Diego-Midnight`.
2. Subir los archivos descomprimidos a la raíz del repositorio.
3. Confirmar que GitHub Pages despliega desde main / root.
4. Abrir en una ventana privada para evitar caché del service worker.
5. Probar alimentos, recetas, favoritos, almacenamiento y navegación antes de reemplazar la app original.

## Seguridad
No se ha validado clínicamente ningún cálculo de insulina. La modificación es visual. El repositorio público no debe contener información sanitaria identificable.
